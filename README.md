# FitLife (MVP v1.0) 🏃‍♂️💧

**FitLife** — простое и удобное консольное приложение на Python для первичной оценки ключевых показателей физического здоровья: индивидуального индекса массы тела (ИМТ) и рекомендуемой суточной нормы потребления воды.

---

## 📌 Функциональность

- **Расчёт ИМТ (BMI)** — вычисление индекса массы тела по стандартной формуле (вес / рост^2) с точностью до одного знака после запятой.
- **Расчёт суточной нормы воды** — определение оптимального объёма жидкости в литрах на основе массы тела (из расчёта 30 мл воды на 1 кг веса).
- **Персонализированный диалог** — обращение к пользователю по имени на каждом этапе ввода данных.

---

## 🛠 Стек технологий

- **Python 3.8+**
- **PEP 8 / Flake8** — строгий стиль и чистота кода.
- **pytest** — автотестирование ключевой логики.

## 🚀 Быстрый старт (локальный запуск)

### 1. Клонирование репозитория

```bash
git clone https://github.com/AquilonissPSN/FitLife.git
cd FitLife
```

### 2. (Опционально) Создание и активация виртуального окружения

```bash
# Для macOS / Linux:
python3 -m venv venv
source venv/bin/activate

# Для Windows:
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
python fit_life.py
# или
python3 fit_life.py
```

### 5. Запуск автотестов и линтера

```bash
pytest
flake8
```
